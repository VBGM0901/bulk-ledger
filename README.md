# 증량 가계부

증량 식단을 **다 먹을 때 드는 돈**과 **실제로 쓴 돈·먹은 양·체중**을 한곳에서 보는 개인용 PWA.

- 데이터는 **폰 안(IndexedDB)에만** 저장됩니다. 서버 없음.
- 개인 금액(월급·고정비 등)은 이 저장소에 없습니다. 앱에서 직접 입력하거나 개인 데이터 파일을 불러옵니다.
- Claude API(캡처 판독·대화)는 브라우저에서 직접 호출하며, 키는 폰에만 저장되고 백업 파일에도 들어가지 않습니다.

## 아이폰 설치

1. Safari로 `https://<github-id>.github.io/bulk-ledger/` 열기
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행 → **더보기 → 설정**
   - **개인 데이터 파일 합치기**: 개인 `seed.json`을 (AirDrop/iCloud Drive로 폰에 옮겨 둔 뒤) 선택
   - **Claude API 키**: Max 요금제 크레딧을 연결한 Console 조직에서 이 앱 전용 키를 만들어 입력 (월 사용 한도 설정 권장) → **연결 확인**
4. **식단** 화면에서 식품마다 "지금 재고 맞추기"를 한 번 입력

## 쓰는 법

| 할 일 | 어디서 |
|---|---|
| 쿠팡 주문·영수증·카드 알림 기록 | 지출 → 캡처 올리기 → 확인 → 저장 |
| 통/봉을 다 먹음 | 식단 → 식품 카드 → 다 먹었음 (실제 섭취량 계산) |
| 저녁 집밥 | 홈 → 고기 있음 / 고기 없음 / 덜 먹음 |
| 체중 | 체중 → 매일 아침 |
| 다음 주문 | 더보기 → 장보기 (로켓프레시 15,000원 묶음) |
| 질문 | 더보기 → Claude에게 묻기 |

## 백업

설정 → **백업 파일 저장** → 공유 시트에서 "파일에 저장"(iCloud Drive). 7일이 지나면 홈에 경고가 뜹니다.

## 개발

```bash
npm install
npm test          # Vitest
npm run build     # tsc + Vite + PWA
npm run preview
```


`main`에 push하면 GitHub Actions가 테스트 후 GitHub Pages로 배포합니다.
